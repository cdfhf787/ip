测试方法有三种，建议至少做前两种：

1. **本地 ping**：Windows 打开命令行或 PowerShell，Mac 和 Linux 在终端输入 `ping IP`（替换成上表的 IP），看 time 值就是延迟，连续 ping 一分钟能顺便看出丢包率。

## 买后怎么查：KiwiVM 面板的 Block List Check

搬瓦工官方检测工具在 KiwiVM 控制面板里，步骤如下：

1. 登录搬瓦工账号，进入 Services → My Services，找到出问题的 VPS；
2. 点击进入 KiwiVM Control Panel；
3. 把浏览器地址栏末尾的 `main.php` 替换为 `main-exec.php?mode=blacklistcheck`；
4. 点击 **Test Main IP**，等几秒出结果。

结果只有两种：绿色的 **IP NOT BLOCKED** 表示正常（下面会附一行带时间戳的原始测试数据，形如 `GFW OK US++++++++++++ CN+++++++++`）；红色的 **IP BLOCKED** 表示 IP 已在阻止列表中。

有个容易踩的坑要提醒：**搬瓦工官方明确说这个测试在中国使用高峰期（晚上）可能不准**。面板原话是建议在一天中不同时段测 2–3 次再下结论。晚高峰测出 BLOCKED 先别慌，第二天白天再测一次确认。

还有一种情况：检测显示正常，但 SSH 还是连不上。先区分是 IP 被封还是端口被封——IP 被封时 ping 也不通；ping 通但 SSH 连不上，多半是你那个五位数的 SSH 端口被拦了，换个端口就能解决（端口号在后台 My Services → Manage → KiwiVM Control Panel 页面能看到）。可以配合第三方工具 port.ping.pe 检查具体端口。确认不是封禁问题的话，试试重启 VPS。

## 查出 IP BLOCKED 之后，实际有三条路

被封不等于机器报废，VPS 在封禁期间保持完全正常运行，海外访问一切正常。可选的处理方式：

**第一条：等它自己解封。** 这是官方推荐的做法。KiwiVM 面板里写得很直白：官方不允许对被封 IP 做任何变更（免费或付费都不行），付费换 IP 目前只是作为礼遇提供的服务，官方并不鼓励使用，因为 GFW 阻断通常会自行清除——只是时间不定，按官方观察从几天到几个月都有可能，取决于阻断原因。

**第二条：付费换 IP。** 免费换 IP 的服务早已下线且不会恢复，目前付费更换是 $8.79/次，需要通过工单联系支持服务台办理。注意两点：一是被封锁期间申请可能不受理，二是这笔 IP 变更费用在退款时不予退还。

**第三条：迁移机房换新 IP。** 切换机房本身免费，切到新机房就得到新 IP，这是最省钱的方式。但有个死结：**IP 处于被封状态时无法迁移机房**，必须等解封或先换 IP 之后才能操作。所以这条路只对「IP 没被封但想换线路」的场景有效。顺带一提，KiwiVM 面板支持一键开启 TCP BBR，对晚高峰的速度和抖动改善有帮助，属于免费就该开的选项。

另外一个和迁移有关的隐藏规则：普通 KVM 套餐迁移到 DC3 CN2 机房时，月流量会变成原来的三分之一，用其他机房则不变。如果你选 DC3 是冲着 CN2 线路去的，记得把流量缩水算进成本。

## 常见问题

**搬瓦工 IP 被封能免费换吗？**
不能。免费换 IP 服务已下线，目前只有 $8.79/次的付费更换，且需通过工单联系客服办理。被封期间官方政策上不接受任何 IP 变更，付费换 IP 属于礼遇性质，能否办理以客服答复为准。

**IP 被封期间可以迁移机房吗？**
不可以。KiwiVM 面板明确提示：IP 被移出阻止列表之前，无法将 VPS 迁移到其他数据中心。想靠切机房换 IP，得先等解封。

**检测显示正常但就是连不上怎么办？**
先确认是 IP 问题还是端口问题：ping 得通说明 IP 没被封，重点查 SSH 端口（搬瓦工默认是非 22 的五位数端口，在后台 My Services → Manage → KiwiVM Control Panel 页面可以看到），用端口检测工具扫一下，被封就换个端口。都不行就重启 VPS，或换时段重新跑一次 Block List Check。

**买之前怎么知道会不会被墙？**
没法保证，任何商家都一样。能做的是买前用测试 IP 看线路质量，买后尽快检测一次 IP 状态——这既是为了确认能正常使用，也关系到 30 天退款资格（黑名单 IP 不符合退款条件）。
